# EchoBound: Riftborn — Expanded Vertical Slice

This version expands the original prototype into a deeper mobile RPG foundation.

## Added
- 5 world regions / 5 story chapters
- 9 enemy types including multiple bosses and a final story boss
- 4 playable heroes with distinct combat identities
- 8 unlockable outfits
- 5 upgrade branches
- Combo system
- Hero-specific combat modifiers
- Quest board with crystal rewards
- Story completion reward
- Offline idle earnings
- Persistent saves
- Mobile-friendly tabbed UI
- Expanded progression and economy
- Procedural UI/visuals with no runtime third-party dependencies

## Production roadmap
This is now a stronger vertical slice. For a commercial launch, the next passes should add:
1. Original animated character sprites and environment tiles.
2. Combat VFX, hit reactions, enemy animations and boss telegraphs.
3. Audio/music.
4. Inventory, equipment rarity, crafting and loot tables.
5. Daily/weekly events and achievements.
6. Cloud save and optional account system.
7. Analytics, crash reporting and privacy-consent flow.
8. Android IAP/ads only after the core loop is polished.
9. Store listing art, screenshots, age rating and legal documents.
10. Full QA on low-end Android devices.
